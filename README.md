# 菊里祭公式アプリプライバシーポリシー

**2026年8月25日制定**  

名古屋市立菊里高等学校生徒会菊里アプリ運営特別委員会(以下,「当委員会」といいます.)は,本アプリ上で提供するサービス(以下,「本サービス」といいます.)における,ユーザーの個人情報の取扱いについて,以下のとおりプライバシーポリシー(以下,「本ポリシー」といいます.)を定めます.

## 第1条(個人情報)

「個人情報」とは,個人情報保護法にいう「個人情報」を指すものとし,生存する個人に関する情報であって,当該情報に含まれる氏名,メールアドレス,連絡先その他の記述等により特定の個人を識別できる情報及び当該情報単体から特定の個人を識別できる情報(個人識別情報)を指します.

## 第2条(個人情報の収集方法)

当委員会は,ユーザーに氏名,メールアドレス,連絡先などの個人情報をお尋ねすることはありません.
第5条に定める運営者向けの機能で使用するアカウントは,当委員会が委員会・部署ごとに発行するものであり,個人名を含みません.
ただし,本アプリは第3条から第5条に定めるとおり,利用状況に関する情報および運営上必要な情報を収集します.これらの情報から特定の個人を識別することはできません.

## 第3条(利用状況の収集)

1. 本アプリは,アプリの改善および次年度以降の運営の参考とすることを目的として,Google LLC の提供する「Firebase Analytics」を利用し,以下の情報を自動的に収集します.

    - 端末の種類,OS の種類とバージョン,アプリのバージョン,言語設定
    - アプリの起動日時,起動回数,利用時間
    - アプリ内で表示した画面,および利用した機能の記録

2. 前項の情報に,氏名・生年月日・連絡先など,特定の個人を識別できる情報は含まれません.また,当委員会が個人を特定する目的でこれらの情報を利用することはありません.

3. 前記の情報は Google LLC のサーバーに保存され,同社のプライバシーポリシー(https://policies.google.com/privacy)に従って取り扱われます.

4. 収集した情報は,統計的な情報としてのみ利用します.

## 第4条(プッシュ通知)

1. 本アプリは,お知らせを配信するために Google LLC の提供する「Firebase Cloud Messaging」を利用します.

2. iOS 版および Android 版では,配信先の指定に「トピック」と呼ばれる仕組みを用いています.端末を識別する情報を当委員会が保存することはありません.

3. Web 版(ブラウザ版)では,通知を許可した場合に限り,ブラウザごとに発行される通知用の識別子を当委員会のデータベースに保存します.この識別子から特定の個人を識別することはできません.通知を許可しなかった場合,保存は行われません.

4. 通知の許可は,端末またはブラウザの設定からいつでも取り消すことができます.

## 第5条(運営者向け機能で取り扱う情報)

本アプリには,菊里祭の運営に携わる委員会・部署のみが利用する機能(以下,「運営機能」といいます.)があります.運営機能を利用しない方に,本条は適用されません.

1. 運営機能の利用には,当委員会が発行したアカウントでのログインが必要です.アカウントには,委員会名・部署名などの所属を表す名称と,利用できる機能の範囲が設定されており,個人名は含みません.

2. 運営機能の利用にともない,次の情報が当委員会のデータベースに記録されます.

    - 問い合わせの本文,送信したアカウントの所属名と識別子,および通知用の識別子
    - 試合結果を登録した部署の名称と,登録した日時

3. 前項の情報は,菊里祭の運営および本アプリの管理のためにのみ利用し,第三者に提供することはありません.

## 第6条(プライバシーポリシーの変更)

1. 本ポリシーの内容は,法令その他本ポリシーに別段の定めのある事項を除いて,ユーザーに通知することなく,変更することができるものとします.
2. 当委員会が別途定める場合を除いて,変更後のプライバシーポリシーは,本アプリに掲載したときから効力を生じるものとします.


## 第7条(お問い合わせ)

在校生徒の方からのお問い合わせは,直接生徒会室にて対応いたします.
その他,データ保護に関するご質問,またはご自分の個人データの問題解決に関するご依頼などは,以下の電子メールアドレスまで,電子メールでお寄せください.
